# The Gallows — Art

Public image files for **The Gallows** RP system's HUD panel in Second Life.
Only artwork lives here; the scripts are in a separate private repository.

The panel loads these images through jsDelivr, pinned to a commit, e.g.
`https://cdn.jsdelivr.net/gh/NovaNightmire/gallows_art@<commit>/logos/vampire.webp`

## Folders
| Folder | Contents |
|---|---|
| `logos/` | Race logos (`human`, `witch`, `vampire`, `oni`, `ghost`) and the Gallows medallion — panel-sized WebP |
| `logos/source/` | Original full-size uploads |
| `frames/` | Metal frames, plates, buttons (later) |
| `backgrounds/` | Panel and race backdrops (later) |
| `icons/` | Skill, attribute and need icons (later) |

File names: lowercase, no spaces (`vampire.webp`, not `Vampire Logo.png`).
